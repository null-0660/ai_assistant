## 🧮 Калькулятор v1.1 — ручной вызов

**Суть:**  
Функция `calculator(a, b, operation)` принимает два числа и операцию,  
возвращает результат.

Поддерживаемые операции:

- `+` — сложение
- `-` — вычитание
- `*` — умножение
- `/` — деление
- `^` — степень (в Python это `**`, а не `^`)
- `%` — остаток от деления

Вызов выглядит так:

    calculator(2, 2, '^')

то есть **числа и операция задаются прямо в коде**.

### ✅ Что работает

- Все базовые арифметические операции.
- Обработка неизвестной операции → строка `'Ошибка: неверная операция'`.

### ❌ Известные ошибки и баги

1. **Нет обработки деления на ноль**  
   При `b == 0` и операции `/` или `%` программа падает с `ZeroDivisionError`.

2. **Нет проверки типов**  
   Если передать строку вместо числа — программа упадёт.

3. **Нет нормализации ввода**  
   Если операция введена как `' + '` (с пробелами) — условие не сработает.


### 🚧 Что можно улучшить

- Добавить проверку `b == 0` для `/` и `%`.
- Добавить `try/except` для некорректных типов.
- Добавить `.strip()` для операции.
- Разбить код на маленькие функции: `add`, `sub`, `mul`, `div`, `power`, `mod`.

## 🧮 Калькулятор v1.2 — ввод через `input`

**Суть:**  
Функция `calculator()` сама спрашивает у пользователя:

- первое число,
- второе число,
- операцию.

Потом считает и печатает результат.

### ✅ Что работает

- Пользователь сам вводит данные.
- Все операции из v1.
- Обработка неизвестной операции.

### ❌ Известные ошибки и баги

1. **Нет цикла**  
   Программа спрашивает **один раз** и завершается.  
   Пользователь не может посчитать ещё раз без перезапуска.

2. **Нет выхода (`exit`)**  
   Нельзя выйти из программы, кроме закрытия терминала.

3. **Нет обработки `b == 0`**  
   Деление на ноль → падение программы.

4. **Нет обработки нечислового ввода**  
   `int(input(...))` упадёт, если ввести `abc`.

5. **`int` вместо `float`**  
   Нельзя ввести `2.5`.

6. **Ввод и логика смешаны**  
   `input` внутри `calculator()` мешает тестировать логику отдельно.

### 🚧 Что можно улучшить

- Разделить на две функции:
  - `calculate(a, b, op)` — чистая логика,
  - `main()` — цикл + `input` + вызов `calculate`.
- Обернуть всё в `while True`.
- Добавить `break` по команде `exit`.
- Добавить проверку `b == 0`.
- Добавить `try/except` вокруг `int()` / `float()`.
- Использовать `float` вместо `int`, если нужны дробные числа.
- Разбить операции на отдельные функции.
