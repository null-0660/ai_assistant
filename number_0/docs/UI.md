# 🎨 Интерфейс Легиона

GUI на tkinter, тёмная тема, минималистичный дизайн.

## Компоненты

### Сайдбар (левая колонка)
- **Логотип** — круг с «◈» и название
- **Кнопки управления:**
  - `🎨 Открыть аватар` — открывает HTML-аватар в браузере
  - `🎤 Запустить голос` — включает микрофон и голосовой режим
  - `⏹ Остановить голос` — выключает (disabled, пока голос не запущен)
- **Статус** — точка-индикатор + текст + подпись
- **Модель** — текущая LLM (без пути, только имя)

### Чат (верхняя правая)
- **Пузыри сообщений** — с аватаркой (круг с буквой), именем, временем
- **Слева** — сообщения ИИ (зелёная аватарка «Л»)
- **Справа** — сообщения пользователя (синяя аватарка «В»)
- **Стриминг** — текст обновляется по мере генерации
- **Автоскролл** — вниз при новом сообщении

### Лог (нижняя правая)
- **Моноширинный** шрифт (Cascadia Mono)
- **Цвета по уровню:**
  - INFO — серый
  - WARNING — жёлтый
  - ERROR — красный
  - DEBUG — тёмно-серый
- **Автоскролл** вниз
- **Кнопка «Очистить»** справа сверху

## Цвета

Из `gui/theme.py`:

| Роль | HEX | Где используется |
|---|---|---|
| Фон | `#0d1117` | корневой, поля ввода |
| Сайдбар | `#161b22` | левая колонка |
| Панели | `#1c2128` | чат, лог |
| Акцент | `#58a6ff` | кнопки, имя пользователя |
| Успех | `#3fb950` | статус "готов", имя ИИ |
| Ошибка | `#f85149` | сообщения об ошибках |
| Пузырь user | `#1f6feb` | фон сообщений пользователя |
| Пузырь AI | `#21262d` | фон сообщений ИИ |

## Кастомизация

Все цвета — в `gui/theme.py`. Чтобы поменять тему:

1. Открой `gui/theme.py`
2. Поменяй HEX-коды
3. Сохрани
4. Перезапусти приложение

Все шрифты и отступы тоже там.
