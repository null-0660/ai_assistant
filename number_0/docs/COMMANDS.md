## 💬 Свободный диалог

Если фраза не подошла ни под одну команду — она уходит в LLM. Примеры:

- «привет»
- «расскажи анекдот»
- «что такое квантовая физика»
- «сколько будет 25 умножить на 4»

Ответ будет коротким (1-2 предложения) — так задумано.
