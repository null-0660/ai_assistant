# ⚙️ Установка и настройка

## Требования

- Python 3.10+
- LM Studio
- Микрофон
- Windows / Linux / macOS

Модели

Скачай отдельно (в репо не включены):
Модель	Куда	Откуда
Vosk RU	model/	alphacephei.com/vosk/models
Silero TTS	v5_ru.pt в корень	models.silero.ai
LLM	LM Studio	Discover в LM Studio
Настройка LM Studio

    Открой LM Studio → Developer → Local Server

    Загрузи модель (рекомендую Qwen3-8B — умнее и лучше на русском)

    Порт 1234

    Проверь: http://127.0.0.1:1234/v1/models
