# Day 02 — 🎲 Random Number Generator (v1)

Второй день челленджа «100 проектов».  
Тема: **`random`, циклы**.

---

## 🎲 Что за проект

Генератор случайных чисел в терминале.  
Пользователь вводит диапазон — получает случайное число.  
Работает в цикле, пока не введёт `stop`.

---

## 📚 Какая библиотека используется

- `random` — встроенный модуль Python для случайных чисел.
- `random.randint(a, b)` — случайное целое от `a` до `b` включительно.

---

## ✅ Что делает v1

1. Спрашивает диапазон: например `1 10`.
2. Генерирует случайное число в этом диапазоне.
3. Печатает его.
4. Повторяет, пока пользователь не введёт `stop` / `стоп`.

---

## 🐛 Баги v1

1. **`IndexError`** — если ввести одно число или пустую строку.  
   Нет проверки `len(parts) != 2`.

2. **Запятая не работает** — `1, 10` ломается.  
   Нужен `.replace(',', ' ')` перед `.split()`.

3. **`5 5` запрещено** — `a >= b` не даёт одинаковые числа.

4. **Нет режимов** — только один: диапазон → одно число.

---

## 🚧 Что можно добавить (v2)

- Проверку длины: `len(parts) != 2`.
- Поддержку запятой: `1, 10`.
- Меню с режимами:
  - одно число,
  - N чисел,
  - уникальные числа,
  - выбор из списка.
- Разбить на функции.
- Обработать `IndexError`.

---

## 🧠 Чему учит

- `import random`, `random.randint(a, b)`.
- `input()` → строка, даже если `1 10`.
- `.split()` → список частей.
- `try / except ValueError` ловит только `ValueError`, не `IndexError`.
- `while True` + `break` + `continue`.
